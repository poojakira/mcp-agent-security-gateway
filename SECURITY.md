# Security Policy

## Scope

`mcp-agent-security-gateway` is a research and portfolio project: a stdlib-first
security monitor for MCP tool calls. It has not been hardened for production or
run at scale. Use it as a reference implementation, not a turnkey control.

## Reporting a Vulnerability

If you find a security issue in this project, please report it privately rather
than opening a public issue:

- Open a GitHub security advisory on this repository, or
- Email the maintainer (see the profile at https://github.com/poojakira).

Please include:
- A description of the issue and its impact
- Steps to reproduce (a minimal proof of concept if possible)
- The affected commit or version

## Supported Versions

This is a pre-1.0 project. Only the latest `main` is maintained; there is no
backport policy.
