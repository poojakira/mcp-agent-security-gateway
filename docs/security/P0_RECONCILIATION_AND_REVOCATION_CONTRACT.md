# P0 reconciliation and revocation contract

Scope: local, cooperating processes using trusted operator configuration. Cross-host deployments remain unsupported and unaccepted; no exactly-once external guarantee.

States: QUEUED and AUTHORIZED are conceptual in-memory states. Durable reservation creates UNCERTAIN **before** dispatch, conservatively covering reserved-but-never-sent, DISPATCHED, externally COMMITTED and lost ACKNOWLEDGMENT. These are not separate durable journal states; do not infer which occurred from UNCERTAIN. No acknowledgment, error, timeout or caller report completes an operation. Legacy `mark_completed` now always rejects.

A trusted permit binds principal (tenant-scoped where verified sessions are used), server, tool, key and canonical arguments. SQLite atomically reserves that tuple. Every key reuse, including identical payload after restart or observed completion, is denied. Tombstones have no automatic expiry or deletion. Never restore/prune state as a retry strategy; restored journal rollback is not protected.

Reconciliation currently supports only the bounded `update_dependency` manifest transformation. The operator supplies a read-only observer and preflight snapshot. Arguments must hash to the reserved intent. Only exact approved semantic state can atomically insert observation evidence and set COMPLETED. Evidence records observer version, workspace, before/observed SHA256, argument hash, wall-clock observation timestamp and point-in-time consistency scope. Missing evidence/table/storage rolls back completion; no automatic external retry occurs. Evidence is local trusted storage, not an independently signed or immutable record.

Resource binding: an operator may provision `effect_verifiers` keyed by operation key on the proxy, or supply `consequence_verifier` directly at reservation. Reservation checks current no-effect preflight, exact arguments, workspace path/device/inode and preflight hash, storing the binding atomically with intent. Reconciliation must match that binding. Different workspace/preflight and unbound legacy intents cannot be completed. Older stores without binding/evidence tables are not silently migrated; preserve them as uncertain, reconcile through an operator-reviewed recovery process, and never replay them. Generic provider/version-aware adapters remain absent.

Observation guarantees: reading a local inode and comparing complete JSON does not prevent writes during/after read, prove a provider performed the change, or establish immutable final state. Versions/ETags/conditional provider operations and observation-to-commit fencing remain acceptance dependencies. FIFO/symlink/oversized/malformed files do not count as successful observations. No-effect, unexpected and indeterminate remain UNCERTAIN.

Revocation: local session/token revocations become visible on each fresh authority read after committed update; no numerical production propagation bound has been measured. A queued request rechecks identity/policy/resource ACL inside its actual send lock. This closes the stale queued-grant window but leaves the network/commit interval. The protected local file adapter holds BEGIN IMMEDIATE through replacement, serializing cooperating revocation acknowledgment after an in-progress effect. A previously committed revoke prevents new effect authorization. It cannot retroactively cancel irreversible effects. External downstream systems need their own fencing/conditional commit; otherwise already-dispatched outcomes remain uncertain and require observation.

Crashes: FULL synchronous WAL and bootstrap directory fsync provide bounded local durability, conditional on filesystem/storage semantics. Runtime never recreates a missing store. Exclusive bootstrap rejects existing stores. Private owned regular single-link files are checked; untrusted same-UID directory mutation and root compromise are not prevented by path checks. Hardware power-loss, storage rollback and cross-host consensus have not been validated.
