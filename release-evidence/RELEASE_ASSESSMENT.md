## Launch and actual task

Use Python3.10+, pip and a browser. Create/activate a venv, run `python -m pip install -e .`, then `python -m mcp_monitor.workbench`; open http://127.0.0.1:8761. No provider key, model or paid service is required. Execute the synthetic note read, attempt a write under Read-only/permissionON, keep the request unchanged and switch permissionOFF, then execute and inspect the actual changed note/receipt. OFF changes the tool allowlist only; other checks remain active. Export redacted evidence and stop with Ctrl-C. README.md and docs/WORKBENCH.md contain complete setup, alternate port, limits, errors and lifecycle.
