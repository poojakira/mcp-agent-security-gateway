Problem & Threat Model
LLM agents can turn untrusted natural-language context
into structured tool calls with file, process, network, or
privileged-service effects. The gateway protects the
agent-to-tool boundary only when traffic is routed through
it. Attackers may craft malicious tool arguments,
malformed JSON-RPC, obfuscated prompt-injection
strings, exfiltration payloads, or abusive request patterns.
